# Changelog

## 1.1.0 - 2026-08-22

- The “Update all reply subjects” checkbox now remains selected after previewing an edited post.
- Dropped support for phpBB 3.1. New minimum requirements are phpBB 3.2.1 and PHP 5.4.
- Modernised the extension to use current phpBB language, event-data, and template APIs.
- Added Arabic, Brazilian Portuguese, French, German, Hebrew, Italian, Polish, and Spanish language packs.
- Improved English wording for the option that updates every reply subject.

## 1.0.0 - 2018-03-30

- First release.
